Bantuan & Tutorial

Panduan Penggunaan Platform Suara Kita

Pelajari cara memilih, mengelola kontes, dan memanfaatkan fitur e-voting secara maksimal.

Panduan Untuk Pemilih (Voter)

1
Dapatkan Kode Token Unik: Panitia pemilu instansi Anda akan memberikan kode token khusus (misal: SK-88X1-992K) via email / WhatsApp.
2
Buka Bilik Suara: Akses halaman kontes instansi Anda, lalu klik tombol "Masuk Bilik Suara".
3
Pilih Paslon/Kandidat: Tinjau visi & misi kandidat, pilih kandidat pilihan Anda, dan tekan "Coblos Pilihan".
4
Selesai & Terverifikasi: Suara Anda tercatat secara anonim & token langsung hangus secara permanen.

Panduan Untuk Panitia (Admin Instansi)

1. Daftarkan instansi Anda di halaman registrasi.

2. Buat kontes pemilihan baru dengan menentukan jadwal mulai dan selesai pemungutan suara.

3. Input profil kandidat/paslon lengkap dengan foto, visi, misi, dan program kerja.

4. Beli paket token sesuai kuota DPT (Daftar Pemilih Tetap) Anda dan unduh daftar token.

5. Bagikan token kepada pemilih dan pantau Quick Count secara real-time pada dashboard admin.
